# Canonical Cells

This directory is reserved for standalone Python versions of important Colab cells.

Naming convention:

- `cell_01_*.py`
- `cell_02_*.py`
- ...
- `cell_13_1_portfolio_audit.py`
- `cell_13_3_oos.py`
- `cell_13_5_robustness.py`

Each migrated cell should be a complete, runnable unit and should not require the user to manually merge fragments into older code.

Do not migrate a notebook cell here until its dependencies and expected inputs are identified.
